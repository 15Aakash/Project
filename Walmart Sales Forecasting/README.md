# 📊 Walmart Sales Forecasting App

This project is an end-to-end time series forecasting application built using Prophet and deployed with Streamlit.

## 🚀 Features

- Forecast weekly sales using Prophet
- Handles seasonality and US holiday effects
- Upload custom datasets
- Store-level filtering
- Adjustable forecast horizon
- Evaluation metrics (MAE, MAPE)
- Downloadable forecast results

## 🛠 Tech Stack

- Python
- Streamlit
- Prophet
- Pandas, NumPy
- Matplotlib

## 📈 Model Details

- Model: Prophet
- Seasonality: Yearly + Weekly
- Holiday Effects: US Holidays
- Performance: ~5% MAPE
